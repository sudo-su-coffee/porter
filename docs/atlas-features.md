## 0. Root: SPEC / CLAUDE / CI / llm

- `SPEC.md`: layout (`atlas/`, `clients/`, `metal/`, `llm/`, `services/http-proxy`, `services/wg-mesh`); no root go.mod (run Go per component); ownership per component.
- `CLAUDE.md`: SPEC-first, small direct changes, no unrelated/generated edits, no `plan_*.md`, binary units (`disk_mib`), `is_/has_` booleans, Go concrete types + `NewType` + wrapped errors + ctx-first, Python thin routes, STE100 docs, Conventional Commits.
- CI: `atlas-ci` (app + atlas-client regen, fail on drift), `metal-tests`, `http-proxy-tests` (+ proxy-client regen), `linter`.
- `llm/`: skills (`quality-code-review`, `code-style`, `technical-writing`, `ui-design`, `grill-me`, `write-pr-description`, `i-have-adhd`, `fastapi`, `ste100-writer`); 68-rule Go anti-pattern guide (no `any`, no generic helpers, small consumer interfaces, no pass-through layers, `errors.Is/As`, decode JSON once at boundary, no DTO duplication, early returns, no gratuitous goroutines, log once, no `recover` for normal errors, no globals, plain SQL).

## 1. `docs/`: architecture / glossary / metal-v1-contract / api-clients

- Ownership: Atlas (providers, Metal Server records, placement, images, IPv4 intent) vs Metal (desired/observed, reconcile, cleanup) vs systemd/FC/mesh/proxy. VM create (lock→draft commit→idempotent PUT→202→reconcile→read); provision flow; capacity sync; image flows (object→cache→disk; disk→staging→object→Machine image; warm never uploaded); failure boundaries (provider/Atlas→Metal/Metal/proxy/mesh).
- Glossary (22 terms): desired/observed state, generation/restart-generation, reconciliation, draft, capacity sample, System/Machine image, snapshot staging, warm artifact, IPv4 intent, mesh, proxy.
- Metal `/v1` contract: JSON+bearer (except health/docs), `mib/mibps/iops`, reject unknown/trailing, persist-before-respond, never leak URLs/userdata/paths/PIDs. Routes: `POST /v1/sync`, `PUT/GET /v1/vms/{id}`, `GET /v1/vms`, `PUT power/compute/disk/network/ssh-keys/metadata`, `DELETE`, `POST restart/snapshots`, `POST /v1/snapshots/{id}/upload`, `GET/DELETE snapshot`, `GET console` WS. Desired vs observed shape, generation progress, error codes + `retryable` + `request_id`.
- api-clients: `openapi-python-client` regen via `generate-api-client(s).sh/.py` (in-memory spec, op-ID = function name, CI fails on drift).

## 3. `metal/` daemon (Go, `github.com/frappe/atlas/metal`)

- `cmd/metald`: `serve [--config]`; wiring (dirs→systemd→stores→WG→mesh→traffic→FC→manager→host→reconcilers→keys→API + migration :9001); `SIGINT/SIGTERM` bounded shutdown (guests survive); JSON logs with request/op IDs; config (`base_dir /var/lib/metal`, `listen`, `auth_token_hash` SHA-256, FC paths, jailer, ZFS pool, wg0, mesh CLI+uplink, traffic, migration deltas/ports).
- `internal/api`: thin async (validate→store→wake→202; poll generations); strict JSON; correlation headers; capacity pre-check 409; SSH/metadata 200-fast/202-slow; group auth (static-bearer / mesh-trust / public); domain→status + `retryable`; console WS tty/ssh; migration routes (static-token + mesh-trust + `?virtual_machine_id=`, TCP disk transport).
- `internal/console`: `SerialBroker` + PTY + bounded ring + systemd fd-store (survives restarts); open→persist→attach(capped)→close→adopt; slow-viewer-drop; `EPOLLHUP/EIO`; `FDStoreMax/Preserve=yes`.
- `internal/firecracker`: `Runtime` + per-op machine + jailer via `EnvironmentFile` + short sock link; launch (PTY→unit→persist→limits→socket→cold|warm); Start/ColdStart/Restore(paused)/RefreshDisk/LimitDisk; saved-state atomic; systemd→FC state map; MMDS builder + live replace; SSH console (ephemeral key→MMDS→netns PTY, host cap); stdlib Unix-socket client (serialized, no keepalive).
- `internal/host`: `POST /v1/sync` handler (priv-addrs→peers→images→wake→list→capacity+states, stop-on-first-error; floor-0 CPU, `MemAvailable`, skip half-written).
- `internal/network` (+`traffic/` eBPF TCX): `LinuxAllocator.Ensure` (stateless: ns→base→prune→veth→internet→IP→mesh→tc); egress uplink/mesh/none; 5-rule IPv4 set (comment-tagged, `-C`-checked); tc ns-end (private lower prio); TAP `tap0`, `vh/vg-<uid>`, guest `.2`/gw `.1`/fixed MAC, UID-derived `/30`; ARP/ND pinning; mesh via WG-mesh CLI + proxy-NDP + IPv6 fwd; `WireGuardManager` complete-set (foreign peers preserved); eBPF observes host→guest unicast TCP only → idle-wake (first-packet loss + restart-baseline caveats).
- `internal/reconciler`: `VM/Image/Migration` passes (ListIDs→N workers→Reconcile on start+interval+wake; timeouts + caps; image policies/cache/warm/prune/staging; migration target advance; log-and-retry).
- `internal/storage`: ZFS (`images/<img>@ready`, `vms/<id>`, `staging/<snap>`, `warm/<key>@ready` + manifest/vmlinux/boot-args/last-used/warm/snapshots/policies files); `EnsureImage` (arch+URL+SHA, conflict on content change); `PrepareBoot/RootFS/Release`; policy replace+idle-prune; `Stage` (UUIDv7)→`StartUpload` (exact-cover fixed parts, restart→pending)→`Delete`; `MigrationTransfer` (`zfs send/recv -s`, resume-token/GUID checks); per-resource locks; warm key = image+shape+FC-compat; `LinkOrCopy` chroot materialization; FC token-bucket disk limits (live, 0=unlimited).
- `internal/platform`: D-Bus units (`metal-vm@<id>` start/stop/kill/reset/status/list/wait/limits), `Run/Output/RunInNetworkNamespace`, fd store.
- `internal/vm` (+`vm_migration/`): desired (`config.json`)+observed (`status.json`) records, startup-validate-never-repair; reconcile per state (start/resume/restore/idle-stop/pause/hard-stop/destroy resume-safe); traffic-armed idle (desired running/observed stopped); saved-state authoritative-if-stopped; phase+op-ID pre-write; migration `MigrationGuard` (source-lock, target-hidden); `WarmImageBuilder`; per-VM locks; migration prepare (reserve→mesh-lock→capacity→IDs→copying, 10m expiry) → copying (bg `zfs recv -s`, GUID verify, checkpoint) → cutover (delta/intervals/30m gate, stop→net-remove→final-snap→receive→net→cold-start→ready, throttle 64→8) → finish (destroy-source→completed) vs abort (rollback, terminal-compact); TCP length-prefixed transport.
- `docs/` (9): architecture (systemd-owned, intent-not-commands); host-layout (all paths + length limits + save/restore cycle); vm lifecycle; storage (two snapshot kinds, grow-only, clone-fast); networking (topology/matrix/filters/`fdaa`+tenant-0/MMDs/peers); api (generations, power/compute, console modes); testing (`dev.sh` provisioner, guest builds, NAT, `metal-development-token`, traffic/idle E2E); development (`gofmt/test/vet/race/openapi/bpf`, SPEC-first); operations (9 runbooks).
- `services/http-proxy` (1–5 regional VMs, IPv6, local maps, `proxy.<wild>`+`proxy-NNN`, `:9000`, Unix sockets, TOML, merged JWKS, `site:*/domain:*/*`+constraints, generations + ack thresholds 1:1/2:2/3:3/4:3/5:3, 300–450ms elections, 100ms heartbeats, snapshot repair; control daemon + OpenResty/Lua routers (site/plain/auto-proxy/ACME/admin/SNI/persisters), error pages, 5 guides, data-plane E2E).
